# Security

Bu private repo secret saklama alanı değildir.

- Telegram tokenı, chat kimliği ve gelecekteki API anahtarları yalnız ortam
  değişkenleri veya yerel `.env` üzerinden sağlanır.
- Private/trade yetkili borsa anahtarı kullanılmaz.
- Secret şüphesinde değer derhal iptal edilir; yalnız Git geçmişinden silmek yeterli
  kabul edilmez.
- Ham piyasa verisi ve çalışma zamanı SQLite dosyaları repoya eklenmez.
